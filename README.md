# FanDesk · Fan Reply Assistant

Локальный прототип в тёмном creator-workspace стиле для подготовки ответов по скриншоту. Он не подключается к Fansly/OnlyMonster и не отправляет сообщения автоматически.

## Установка Node.js

Скачай официальный **Node.js LTS** для Windows с [nodejs.org](https://nodejs.org/en/download/). После установки закрой и заново открой PowerShell.

## Запуск

1. Установи Node.js 18+.
2. Открой PowerShell в этой папке.
3. Запусти `node server.js`.
4. Открой http://localhost:8787.

Без ключа приложение использует локальный безопасный генератор, чтобы интерфейс работал сразу. Для генерации через OpenAI задай переменные окружения перед запуском:

```powershell
$env:OPENAI_API_KEY="твой_ключ"
$env:OPENAI_MODEL="gpt-4o-mini"
node server.js
```

Ключ хранится только в окружении сервера и не попадает в браузер.

## Возможности

- OCR скриншота в браузере;
- анализ тона и темы;
- три варианта ответа;
- стили «тёплый», «зумерский», «игривый», «элегантный»;
- сценарии лёгкого романтического флирта;
- персонализированные черновики рассылки;
- копирование отдельного варианта.

Главная панель разделена на две вкладки: «Ответы фанам» и «Рассылки». Внутри рассылок есть отдельный режим `Flirty scripts` для безопасных романтических сценариев.

## Режимы генерации

- **Fast** — быстрый короткий ответ;
- **Smart** — баланс контекста и скорости;
- **Creative** — больше разнообразия и неожиданных формулировок.

Генерация ответов настроена на английский язык. В каждый запрос добавляется случайный seed, а локальный режим использует случайные варианты, поэтому тексты не должны повторяться дословно.

Для стиля `genz` добавлен lowercase-режим без апострофов и заглавных букв, с естественными сокращениями вроде `hehe`, `tbh`, `wyd`, `ngl`, `idk`, `lol`, `lmao`, `:3` и `<3`. Встроен фильтр слов из жёсткого бана Fansly и отдельная пометка для терминов, требующих ручной проверки.

## Ссылка для друзей

Для URL, который открывается в браузере без установки программы, разверни проект на любом Node.js-хостинге. В репозитории уже есть `render.yaml` для Render:

1. Создай репозиторий на GitHub и загрузи эту папку.
2. На Render выбери **New → Blueprint** и подключи репозиторий.
3. Введи `OPENAI_API_KEY` в настройках сервиса.
4. Render выдаст публичную HTTPS-ссылку вида `https://fandesk-ai-....onrender.com`.

Ссылку можно передать друзьям; им нужен только браузер. Не вставляй API-ключ в HTML или ссылку.

Генератор специально не создаёт откровенный сексуальный контент, не определяет возраст по изображению и требует ручной проверки перед отправкой.
